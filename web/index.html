新增紧急订单

输入订单属性后，系统先校验数据、网络、事件时刻、运力和硬时间窗，再执行动态重规划。

插单校验规则
  1. 订单 ID 唯一、需求量大于 0，时间窗起点不晚于终点。
  2. 模板欧氏网络可按坐标生成路段；其他网络需在数据文件中补全双向距离与时间。
  3. 可用车辆、单车容量、系统总运力、事件时刻和最早可达时间均需满足。
  4. 求解后再次独立校验容量、硬时间窗、客户唯一覆盖和车辆状态。

车辆与时间窗事件

车辆停运规则

仅列出仍可操作的车辆；发车前车辆可停运，在途车辆需先完成当前服务边界并提供救援/转运条件。

重规划策略：在途车辆从当前位置回仓，计入返程和等待制冷成本；全部到齐后统一重新分配货物。
